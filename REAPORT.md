# Bài 1: Kiểm tra Docker Engine và chạy Hello-World

## 1. Môi trường thực hành

- Hệ điều hành: Ubuntu 22.04.5 LTS (VPS)
- Docker Engine: 29.1.3
- Tài khoản thực hiện: root

## 2. Kiểm tra phiên bản Docker

Lệnh thực hiện:
`docker version`

Kết quả: Docker CLI và Docker Engine đã được cài đặt.

## 3. Kiểm tra Docker Daemon

Lệnh thực hiện:
`docker info`

Kết quả: Docker Daemon hoạt động và trả về thông tin hệ thống.

## 4. Chạy Container Hello-World

Lệnh thực hiện:
`docker run hello-world`

Kết quả:

`Hello from Docker!`

`This message shows that your installation appears to be working correctly.`

## 5. Kết luận

Đã cài đặt Docker Engine thành công, kết nối được Docker Daemon và chạy Container Hello-World.
